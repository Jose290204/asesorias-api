# 🎓 Asesorías FIC · API

**El motor detrás del sistema de asesorías y tutorías de la Facultad de Informática Culiacán (UAS).**

Este repositorio es la parte que trabaja en silencio para que Asesorías FIC funcione: cuida la información, mantiene todo en orden y asegura que cada persona tenga acceso solo a lo que le corresponde.

Fue creado pensando en crecer: hoy sirve a la Facultad de Informática Culiacán y está preparado para acompañar a más facultades de la Universidad Autónoma de Sinaloa.

El rostro del sistema, lo que ven y usan estudiantes y asesores, vive en su propio repositorio: [Asesorias-FIC-web-new](https://github.com/Jose290204/Asesorias-FIC-web-new).

Desarrollado por estudiantes de la Facultad de Informática Culiacán, UAS.
